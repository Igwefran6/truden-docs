## Features

<CardGrid stagger>
  <Card title="5 Built-in Triggers" icon="rocket">
    Trigger the snip overlay with Alt+Shake mouse gesture, configurable keyboard shortcuts, touchscreen hold, floating button, or custom DOM events.
  </Card>
  <Card title="Powered by SnapDOM" icon="puzzle">
    High-fidelity DOM rasterization with native support for video frames, canvases, nested iframes, custom web fonts, and sub-pixel reconciliation.
  </Card>
  <Card title="Mode A & Mode B" icon="seti:graphql">
    Direct raw image Blobs to your frontend AI chat copilot or POST to server Vision LLM adapters (Vercel AI SDK, OpenAI, Anthropic, OpenRouter).
  </Card>
  <Card title="100% Framework Agnostic" icon="open-book">
    Standard Web APIs compliance means drop-in compatibility across React, Next.js, Svelte, Vue, Angular, TanStack Start, SolidJS, and Vanilla JS.
  </Card>
</CardGrid>
